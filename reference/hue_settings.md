# Set IP and username to interact with the api

Set IP and username to interact with the api

## Usage

``` r
hue_settings(ip = NULL, username = NULL)
```

## Arguments

- ip:

  A character vector of length one. The IP of your hue bridge, e.g.
  "192.168.0.1"

- username:

  A username generated to interact with the API. For details,
  https://developers.meethue.com/develop/get-started-2/
